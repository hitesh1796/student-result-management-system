# 🎓 Student Result Management System

A beginner-friendly Python project that manages student information and generates student result reports. This project uses Object-Oriented Programming (OOP) concepts to store student details, subjects, and marks.

## ✨ Features

- Store student name and roll number.
- Add subjects and their marks.
- Display student result reports.
- Calculate total marks and percentage.
- Display student performance.
- Organize code using Python classes and methods.

## 🛠️ Technologies Used

- **Language:** Python
- **Concepts:** Object-Oriented Programming (OOP), Classes, Objects, Lists, and Methods

## 🚀 How to Run

1. Install Python on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/hitesh1796/student-result-management-system.git
   ```

3. Open the project folder:

   ```bash
   cd student-result-management-system
   ```

4. Run the Python program:

   ```bash
   python "student result management system.py"
   ```
